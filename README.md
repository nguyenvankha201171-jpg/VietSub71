# VietSub71

Anime Vietsub web app using Node.js, Express and SQLite.

## Run locally

- Install Node.js 20+
- Run `npm install`
- Set `ADMIN_EMAIL` and `ADMIN_PASSWORD` to create an administrator account on first startup.
- Set a long random `JWT_SECRET` in production.
- Run `npm start`

## Render Free

This repository includes a free web service Blueprint. SQLite data on the free service uses ephemeral storage and may be lost after restart or redeploy. Use only authorized video and subtitle URLs.
